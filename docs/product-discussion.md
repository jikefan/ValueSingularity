# 产品讨论记录

## 商业化思路与产品价值定位（2026-11-22）

先把结论放前面：**想靠这个项目赚偏被动的收入，完全有机会，但前提是你卖的不是「行情」也不是「买什么股票」，而是「帮人少踩坑的排雷效率」和「管住手的复盘纪律」。**

下面从产品价值、合规与运维陷阱、具体变现路径三个层面拆开聊。

### 1. 这个项目的真正价值在哪里，别人为啥愿意付钱

先把散户**不会**花钱买的东西剔除掉。A 股的基础行情、PE/PB 数字、三大财务报表和 K 线图，东方财富、同花顺、雪球全部免费。如果你把 ValueSingularity 做成一个“更好看的看盘软件”，基本没人会掏钱。

真正能让人每年稳定付费 200 到 500 元的价值，其实藏在你已经在 [models.py](file:///Users/jikefan/code/projects/value-singularity/apps/api/app/db/models.py#L48-L65) 和 [roadmap.md](file:///Users/jikefan/code/projects/value-singularity/docs/roadmap.md#L24-L45) 里埋好的三块能力上：

- **帮忙碌的赚钱人省下 80% 财报排雷时间。** 目标用户不是天天盯盘的短线游资，而是有本职工作、手里有 20 万到 500 万资金的中产专业人士，比如工程师、医生、小企业主。他们想做基本面投资，但下班后没精力去翻十年年报算自由现金流、核对商誉减值、拆解毛利率和应收账款异常。你把 4 小时的脏活压缩成一份 3 分钟能看完的 9 维体检单，尤其是把「看空逻辑」和「财务排雷」直接拍在脸上，这就值回票价。
- **市场上唯一「不鼓励你频繁交易」的工具。** 券商软件和免费财经 App 靠交易佣金和流量广告赚钱，产品设计天然在制造焦虑、推热点、诱导你多买卖。而独立付费工具的商业利益可以和用户完全一致：**帮用户少出手、少亏钱。** 一年只要帮用户躲过一次看似便宜实则暴雷的价值陷阱，省下来的钱就够付十年的订阅费。
- **治疗「买入前头脑发热，买入后篡改记忆」的复盘系统。** 散户亏钱最大的原因不是不懂公式，而是买入时想着拿三年吃分红，跌 15% 时看着消息面恐慌割肉，事后还忘了当初为什么买。你设计的 `journal` 表强制用户填写 `reason` 和 `falsify_condition`，并在买入瞬间自动把当时财务估值放进 `snapshot` 做时间胶囊，几个月后拿「当时的逻辑」对照「现在的现实」做胜率归因。理杏仁擅长算数据，雪球擅长看情绪，但把「确定性研究」和「行为纠偏复盘」焊死在一个闭环里的工具，市面上非常稀缺。

### 2. 赚钱前必须避开的两个陷阱

在讨论怎么收钱之前，有两个坑不绕开，项目要么封号要么变成全职苦力，根本谈不上被动收入。

- **合规红线。** 在国内做证券软件，没有证监会颁发的证券投资咨询牌照，绝对不能向付费用户推荐具体股票、给出目标价或者买卖信号，那属于非法荐股。ValueSingularity 必须死守「研究效率工具 + 个人日记本 + 客观事实计算器」的定位，就像你在 [App.tsx](file:///Users/jikefan/code/projects/value-singularity/apps/web/src/App.tsx#L19) 页脚写好的免责声明一样，AI 层也只能针对用户自己选的标的做数字引用和风险质询，绝不做荐股推荐。
- **数据源陷阱与伪被动收入。** 如果你把服务搭在云端收年费，后端却继续裸用免费的 `akshare` 爬虫，那你得到的不是被动收入，而是 24 小时救火队。免费网页接口隔三差五限流封服务器 IP 或改字段名，一旦开盘期间大面积报错，用户退款和客服工单会直接把你拖垮。

### 3. 三条可落地的商业化路径，按被动程度排序

#### 路径一：软件授权 + 清洗数据包订阅，最接近真正的被动收入

这是我最推荐优先跑通的模式，参考 Obsidian Sync 或早期理杏仁的思路。

- **怎么交付。** 既然项目本身就是零外部 CDN 的单机优先架构，后期可以用 Tauri 或一键 Docker 包做成桌面本地端，用户安装后跑在自己的电脑上，投资日记和自选隐私完全不出本机。
- **怎么避开爬虫运维。** 软件本身买断或按年授权，同时你在云端只跑一台极低成本的定时任务机器，每天收盘后通过稳定的商用接口或合规源把全市场日线和财报清洗成标准 Parquet 压缩包，传到对象存储和 CDN 上。付费用户打开客户端自动增量拉取这包现成数据，本地 DuckDB 秒级出数。
- **为什么最接近被动。** 静态数据文件走 CDN 分发几乎没有并发数据库压力，服务器成本极低，也没有云端泄露用户交易日记的合规包袱。
- **参考定价。** 免费版放开大盘温度计和有限个股查看。个人专业版定价 199 到 299 元每年，或者 399 元买断基础端加上 149 元每年的数据同步与策略更新订阅。只要做到 500 个稳定续费用户，每年就是 10 万到 15 万的净现金流，维护成本极低。

#### 路径二：商业版 SaaS 订阅 + 用量制 AI 质询

这也是我们刚敲定采用 PostgreSQL 17 加 `psycopg` 3 全异步架构的用武之地，适合面向不想折腾本地安装、希望手机和电脑随时同步的网页用户。

- **数据源必须合规化。** 商业 SaaS 切忌裸跑爬虫，必须采购正规商用数据授权，比如购买商用金融数据 API 或企业级权限，把成本摊进订阅费里。好在你的 `market_snapshot` 和 `stock_snapshot` 设计是全平台共享预计算结果的，5000 只股票每天收盘算一次放进数据库，无论来 100 个还是 1 万个用户查个股，后端只走一次数据库查询，几乎不额外消耗第三方接口配额。
- **分层收费结构。**
  - **免费层。** 开放全市场估值温度计，每天限查 3 只个股和最多 5 只自选，用来拉新转化。
  - **Pro 会员，29 到 49 元每月或 299 元每年。** 开放完整 9 维体检、全行业筛选、无限投资日记时间胶囊、个人判断胜率看板，以及规则版否证条件触发通知，比如某只自选股 PE 跌破设定分位或财务指标触发警报时推送到微信或飞书。
  - **AI 质询额度包，按次或 99 元每月高阶版。** 不打包进基础会员以免亏损，按大模型实际消耗设月度额度或者支持用户自己填 API Key。用户最愿意为「拿着我的买入理由和最新财报，用巴菲特或空头视角狠狠质疑我一次」这种深度交互买单。

#### 路径三：内容获客飞轮，解决「做出来没人买」的问题

很多独立开发者最大的误区是以为做好功能就会有人来付费。投资工具天然需要极高的信任门槛，没人会为一个陌生网站掏 300 块钱。

- **前期靠内容换信任，不靠买广告。** 等 Phase 1 和 Phase 2 跑通后，直接用 ValueSingularity 生成的暗色金融终端风格图表，每周在雪球、小红书、即刻和 B 站发三类固定内容：A 股市场温度与股债性价比周报、热门白马股的 9 维财务排雷拆解、以及你自己用时间胶囊做出的真实交割复盘。
- **先卖高客单价服务，再反哺软件自动化。** 前期软件功能还在打磨时，可以先做「工具会员 + 价值投资排雷清单模板 + 极客复盘圈子」，收几十个首批种子用户 499 到 999 元，直接拿他们的真实痛点指导你写 Phase 2 的公式和 Phase 3 的复盘界面，同时完成冷启动回本。

### 4. 给下一步开发的聚焦建议

如果目标是赚到第一批稳定付费用户，建议你在功能优先级上做一次取舍：

1. **优先做重 Phase 2 的「看空排雷」和「估值安全边际」。** 不要把精力花在和同花顺比 K 线多炫酷上，把「商誉占比过高、利润与现金流背离、股权质押比例、历史估值分位带」做出一眼看懂的预警，这是最直接的付费钩子。
2. **把 Phase 3 的「时间胶囊 + 否证条件提醒」做出不可替代性。** 数据谁都能抄，但用户自己花半年记下的 50 篇带心理状态和当时估值快照的投资日记，以及基于这些日记算出的个人能力圈报告，一旦沉淀在你的系统里，留存率会极高，明年大概率继续续费。
3. **先把商业数据来源和计算口径写透明。** 个人付费者极度反感黑盒评分。你的五维评分和估值公式每一步都要能让用户点开看到计算过程和原始年份数据，建立「专业、克制、不忽悠」的品牌调性，这本身就是最好的护城河。

你更倾向于先按**轻量本地桌面端加数据包**冷启动，还是直接往**多用户云端 SaaS** 这条路走呢？定好方向后，后面 Phase 1 接数据源和用户体系时就能直接对齐。

## 核心增值功能规划与阶段映射（2026-11-22 确认落地）

围绕「帮人省下排雷时间、管住冲动交易、严守不荐股合规红线」三条原则，确认将以下七项高价值能力正式纳入后续产品路线，详见 [roadmap.md](roadmap.md)。

### 1. 排雷与估值核心能力（Phase 2 主力付费点）

- **A 股本土财务排雷 CT 机。** 用确定性规则扫描存贷双高、在建工程多年不转固、净利润与自由现金流长期背离、应收账款周转天数异常拉长、商誉占净资产比重过高、大股东高比例股权质押、年报前更换审计机构或非标审计意见等交叉风险信号。每条红黄灯预警必须直接追溯并展示触发年份与原始会计科目数值，杜绝黑盒评分。
- **真假高股息体检器与股东净回报率。** 计算过去 5 到 10 年的「累计分红加上注销式回购，减去 IPO、定增与可转债等股权再融资」真实净回报，同时计算自由现金流对分红的覆盖倍数，筛出「表面高股息、实则边分红边向市场抽血」的伪红利标的。
- **逆向估值反推器，即 Reverse DCF。** 不要求用户拍脑袋填写未来十年增速和折现率，也不违规给出主观目标价；而是根据当下真实总市值，反向算出当前股价隐含了未来十年每年多少的自由现金流年化增速，并与过去五年实际增速对照。
- **同行业多标的横向同台对比矩阵。** 基于 DuckDB 与 Parquet 列式扫描底座，支持把 3 到 5 只同类公司在同一张表里对齐五年平均 ROE、现金流含金量、净负债率、股东净回报率与各自十年 PE/PB 历史分位。

### 2. 工作流黏性与个人数据护城河（Phase 1 至 Phase 3 留存核心）

- **击球区价格哨兵与否证条件自动雷达。** 把自选股从简单清单升级为「估值愿望单」，支持设置客观估值门槛（例如 PE 低于近十年 20% 分位、股息率高于预设阈值或主观安全边际价格），并将投资日记的 `falsify_condition` 结构化为规则阈值。每日盘后快照批处理完成后，命中买点或否证红线即通过微信或飞书推送冷静提醒。
- **决策质量资产负债表与「看过没买」观察池。** 在投资日记与时间胶囊之上补齐三块归因：自动挂钩同期沪深 300 涨跌幅剥离大盘运气，按买入时填写的 `emotion` 标签交叉统计各情绪状态下的长期胜率与收益率，并允许记录「研究完决定放弃」的 Pass 观察日志，半年后回看躲坑与卖飞对照。

### 3. 克制且高价值的 AI 增强能力（Phase 4 高阶订阅/用量包）

- **年报口径变化对比器（MD&A Diff）。** 对比企业连续两期定期报告中管理层讨论与分析、风险提示、会计政策与坏账计提比例的措辞增删，把删掉的扩张承诺或新增的需求借口高亮列成对照表。
- **买入前「魔鬼代言人」安检门。** 在用户提交买入日记前触发一次强制反方质询，AI 读取后端算好的确定性财报排雷数据与用户买入理由，专门站在空头立场列出三条最可能亏钱的逻辑漏洞，经用户确认或补全否证条件后再落库。

### 4. 明确划清的功能边界

- 不接自动化实盘券商下单接口，避免账户风控封号与业务合规风险。
- 不做广场晒单社区或大 V 讨论区，避免内容审核泥潭与连带荐股风险。
- 不卷日内高频技术指标与量化回测，专注「低频深研 + 长期决策复盘」。
