# 路线图

按"能验证"的顺序排：每一阶段都有可跑通的验收标准，不堆功能。

## Phase 0 · 骨架（本次，已完成）

- [x] monorepo：`apps/api` + `apps/web` + `docs` + `scripts`
- [x] 后端分层与契约（`domain/models.py`、`domain/ports.py`）
- [x] 市场垂直切片：`GET /api/market/overview` → 首页渲染（评分环 + 指数 + 资金流图/表）
- [x] 前端工程化：Vite + React + TS + ESLint + Vitest + `tsc --noEmit`
- [x] 质量门禁：`make lint` / `make test` / CI

**验收**：`make install && make dev` 能打开市场页；`make lint && make test` 全绿。

## Phase 1 · 数据层

- [ ] `adapters/akshare`：指数、PE 历史、国债、行业资金流
- [ ] 缓存与韧性：磁盘缓存、TTL、超时、重试、多源降级（沿用 demo 的成熟策略）
- [ ] `user.db`：自选 / 日记 / 事件三张表 + 仓储
- [ ] Playwright 冒烟：市场页无报错、数据非空

**验收**：断网时能返回缓存并标注数据时间；单测不联网。

## Phase 2 · 分析引擎

- [ ] 财务三表、估值（PE/PB 分位 + DCF + 格雷厄姆 + PEG）、护城河六维、看空逻辑、五维评分
- [ ] 个股 9 Tab 逐个接上，先用 fixture 快照测试锁住输出
- [ ] 每个引擎一页设计说明（输入、公式、边界）

**验收**：任选 3 只股票，9 个 Tab 都能出数；引擎有快照测试。

## Phase 3 · 决策闭环

- [ ] 投资日记（必填理由 + 否证条件 + 最大回撤 + 情绪）
- [ ] 时间胶囊：记录时快照关键指标，之后对比
- [ ] 判断质量：正确率、平均涨跌、能力圈

**验收**：记一条日记 → 三个月后能看到"当时 vs 现在"的对照。

## Phase 4 · AI

- [ ] 先规则后模型：规则版关注雷达（零成本、零幻觉）先上线
- [ ] LLM 决策伙伴：上下文裁剪 + 成本闸门（每用户每日上限）+ 输出必须引用已算好的数字
- [ ] 评估集：固定 20 个质询场景，人工打分回归

## 非目标

云原生微服务、社区、港美股、替代数据。等单机版本有人天天用再说。
